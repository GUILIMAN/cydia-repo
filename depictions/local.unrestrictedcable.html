Unrestricted Cable

1.0.0-1 · local.unrestrictedcable

Completely bypasses the MFi certification check for Lightning cables and chargers — no “this cable or accessory is not certified” popup, no charge suspension, always-on.

Single 51 KB dylib, no dependencies beyond Cydia Substrate. Every hooked selector was verified against the SpringBoard binary of iPad2,5 iOS 9.3.5 (13G36) before compilation.

What it patches

SBUIControllerisConnectedToUnsupportedChargingAccessory → NO
SBUIControllersetIsConnectedToUnsupportedChargingAccessory: → swallowed
SBUIControllerisConnectedToChargeIncapablePowerSource → NO (forces charging)
SBLockScreenViewController_unsupportedChargingAccessoryStateChanged: → alert never built
SBApplicationsuspendingUnsupported → NO

Compatibility

iOS 8.0 – 9.x · armv7 / armv7s devices (built & verified on iPad mini 1, iOS 9.3.5/9.3.6)

Requires: Cydia Substrate (installed with any jailbreak)

Kill switch

Create /var/mobile/Library/Preferences/local.unrestrictedcable.plist containing { Enabled = false; } and respring to disable. Delete the file to re-enable.

Safety notes

This only bypasses iOS's software verdict.

The PMIC's hardware electrical protections are untouched — a genuinely dangerous charger is still cut off. iAP2 data-session authentication (some car kits / audio docks) happens inside iap2d and is not patched. Use decent-quality cables and chargers.
